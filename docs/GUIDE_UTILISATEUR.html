1. Démarrage rapide

Le générateur de devis crée des devis PDF professionnels en moins de 5 minutes : numérotation automatique, calculs exacts (HT / TVA / TTC) et historique consultable. Tout se passe sur votre ordinateur, aucune installation ni connexion internet nécessaire.

Étape 1 : Double-cliquez sur le fichier index.html (dossier app/). L'application s'ouvre dans votre navigateur (Chrome recommandé).
Étape 2 : Cliquez sur « + Nouveau devis », remplissez le client et les prestations : les totaux se calculent tout seuls.
Étape 3 : Cliquez sur « 💾 Enregistrer » : le devis reçoit un numéro automatique (DEV-2026-001…).
Étape 4 : Cliquez sur « 🖨️ Exporter PDF » et choisissez « Enregistrer au format PDF » pour envoyer le devis à votre client.

💡 Astuce : pensez à exporter régulièrement vos devis via Réglages → Exporter pour garder une sauvegarde portable (fichier devis.json).

3. Parcours utilisateur (workflows)

Parcours 1 — Créer un devis de A à Z

1. Ouvrez l'application (double-clic sur index.html)
2. Cliquez sur « + Nouveau devis »
3. Saisissez le client (nom obligatoire, contact optionnel)
4. Renseignez les prestations : libellé, quantité, prix unitaire — les totaux se calculent en direct
5. Vérifiez la TVA (18 % par défaut), ajoutez notes et conditions de paiement si besoin
6. Cliquez sur « 💾 Enregistrer » → le devis reçoit son numéro (DEV-2026-001) et apparaît dans la liste
7. Cliquez sur « 🖨️ Exporter PDF » → « Enregistrer au format PDF » → envoyez le fichier à votre client

Parcours 2 — Modifier un devis existant

1. Dans la liste, cliquez sur ✏️ à côté du devis
2. Modifiez les champs souhaités (prix, lignes, statut…)
3. Cliquez sur « 💾 Enregistrer » — le numéro et la date d'origine sont conservés

Parcours 3 — Suivre le statut d'un devis

1. Ouvrez le devis (✏️)
2. Changez le statut : brouillon → envoyé → accepté / refusé
3. Enregistrez — le statut est conservé et visible dans la liste

Parcours 4 — Sauvegarder et changer d'ordinateur

1. Allez dans Réglages
2. Cliquez sur « ⬇️ Exporter » → le fichier devis.json est téléchargé
3. Sur l'autre ordinateur : Réglages → « ⬆️ Restaurer » → choisissez ce fichier → tous vos devis reviennent

4. Questions fréquentes

L'application ne s'ouvre pas sur mon ordinateur ?

Vérifiez que vous double-cliquez bien sur index.html dans le dossier app/. Utilisez Chrome ou Edge pour le meilleur rendu du PDF.

Où sont stockées mes données ?

Dans votre navigateur (localStorage). Elles restent sur votre machine — c'est volontaire (pas de cloud). Pensez à exporter régulièrement le fichier devis.json pour sauvegarder.

Comment changer la devise (€ → GNF) ?

Réglages → champ « Devise » → saisissez le symbole souhaité → « 💾 Enregistrer les réglages ».

Puis-je créer une facture à partir d'un devis ?

Pas encore — c'est prévu dans une version future. Le devis accepté servira de base.

Un devis supprimé peut-il être récupéré ?

Uniquement si vous avez exporté un devis.json avant la suppression (Restaurer le fichier).
