# Générateur de devis

> Projet test du Process AAS V0.2.1 (mode léger) — 2026-08-02
> Statut : **V1 validée par Ams le 2026-08-02** ✅ — test terrain du process RÉUSSI 🟢

## Objectif

Produire des devis PDF professionnels pour l'activité PME/freelance (sites vitrines, CRM école, digitalisation) en quelques minutes, avec numérotation automatique et historique local.

## Mode

Léger (pas de comptes, pas de paiement, pas de données sensibles, usage local mono-utilisateur).

## Utilisation

Double-cliquer sur **`app/index.html`** (Mac ou Windows, navigateur Chrome conseillé). Aucune installation.

## Guide utilisateur & code source

- 📖 **Guide utilisateur en ligne** : https://amsclaw.github.io/generateur-devis/GUIDE_UTILISATEUR.html
- 📦 **Code source** : https://github.com/amsClaw/generateur-devis

## Prochaine action
